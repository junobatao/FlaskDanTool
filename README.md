# 排单小工具：

### 一、适用人群

在湖州织里童装城，做电商，从3E3E生意网上下载产品图片，上传到电商平台，出单后需要去供货厂家门店拿货发货的中小商家！

### 二、解决问题

如今电商流量分散，单品出爆款的几率越来越低，要想稳住单量，一种简单的做法是选择不停的上新款，上10个款出1单，上1000个款就能出100单！ 上的产品太多太分散，拿货的时候就需要线下跑很多家门店，比如有50家厂家，门店在不同的地址，东边一个西边一个，拿货效率很低，特别是不熟悉路线的人！急需要一个功能把拿货单自动整理合并，再按某个路线排序（不绕路），一家一家的去拿，提高拿货效率！

### 三、技术选型 & 运营部署

- Flask+Sqlite+ES6+Bootstrap5：极简，无需安装数据库，无需生产环境部署，直接本地运行开发环境！

## 四、Vibe Coding

真实业务一直在用5年前写的PHP版本，最近在整理技术栈，顺便用 Copilot 重构了一款Python版的（项目框架和数据库是手工，其它是AI）；
